    Sobre

    O EMC Forge une as ferramentas principais para o ecossistema Minecraft Bedrock:

    • injeção de EMC em ProjectE
    • combinação de packs em um único .mcaddon
    • organização de load order para dependências
    • ore booster para aumentar geração de minérios

    Tudo funcionando em um único site profissional, responsivo e pronto para GitHub Pages.
