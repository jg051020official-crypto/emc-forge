# EMC Forge

Site em HTML/JavaScript para:
- injetar itens EMC em arquivos ProjectE
- analisar mods externos com arquivos `.mcaddon`, `.mcpack` e `.zip`
- organizar o `load order` de packs Bedrock
- gerar um `Master Pack` final

## Como usar

1. Abra o arquivo `index.html` em um navegador.
2. Use o menu de 3 linhas para alternar entre:
   - `EMC Forge`
   - `Load Order`
   - `Sobre`
3. Para publicação pública no GitHub Pages:
   - envie para um repositório GitHub
   - habilite `Settings > Pages`
   - use a opção `Deploy from a branch`
   - escolha `main` e a pasta raiz

## Observações

- A funcionalidade de EMC funciona no navegador e gera um arquivo modificado com base no `_bundle.js`.
- A funcionalidade de load order gera um pacote final em `.zip`, que pode ser renomeado para `.mcpack`.
